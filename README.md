# Неделя открытий — Science

Интерактивная научная вселенная о двенадцати учёных и их открытиях.

## Запуск

Откройте `index.html` в браузере или посетите опубликованную страницу GitHub Pages.

## Возможности

- Интерактивная орбитальная карта из 12 учёных.
- Перемещение карты мышью или пальцем.
- Масштабирование колёсиком мыши или жестом двумя пальцами.
- Биографии, достижения, хронологии и источники по каждому учёному.
- Адаптация для компьютеров и мобильных устройств.
