# Неделя открытий — интерактивный сайт

Готовый адаптивный сайт на чистых HTML, CSS и JavaScript. Никакие сборщики и библиотеки не нужны.

## Как запустить

1. Распакуйте папку проекта.
2. Откройте `index.html` в современном браузере (Chrome, Firefox или Edge).
3. Нажмите **«Учёные»** — орбитальная схема раскроется. Нажимайте на планеты, чтобы открывать статьи.
4. Наведите курсор на чёрную дыру, чтобы увидеть портрет Эйнштейна. Нажмите на неё, чтобы запустить режим «Относительности».

Для локального сервера можно открыть терминал в папке проекта и выполнить:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Файлы

- `index.html` — структура сайта и модальные окна.
- `styles.css` — базовые компоненты и анимации.
- `redesign.css` — обновлённая цветовая система, типографика и отдельная тема Эйнштейна.
- `script.js` — орбитальная карта, карточки учёных и режим относительности.

## Примечания

- Портреты загружаются с внешних исторических и музейных сайтов, поэтому для их отображения нужен интернет. Шрифты Literata, Onest и IBM Plex Mono подключаются через Google Fonts; при отсутствии интернета будут использованы системные шрифты. Остальная часть интерфейса работает локально.
- Внизу каждой статьи приведены ссылки на использованные справочные материалы.
- Для посетителей, предпочитающих уменьшенное движение, поддерживается системная настройка `prefers-reduced-motion`.
