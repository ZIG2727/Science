# Неделя открытий — Science

Космический научный архив о двадцати четырёх учёных, их идеях, открытиях и историческом наследии.

## Запуск

Откройте `index.html` в браузере или посетите опубликованную страницу GitHub Pages.

## Возможности

- Интерактивная карта из 24 учёных, расположенных в шестиугольной системе колец вокруг Галилео Галилея, с анимированными светящимися орбитами и индивидуальными фонами карточек учёных.
- Перемещение камеры мышью или пальцем.
- Масштабирование колёсиком мыши или жестом двумя пальцами.
- Биографии, открытия, хронологии и источники для каждого учёного.
- Космический интерфейс с фиолетовой палитрой, адаптивной сеткой и научной визуализацией.
- Экранные кнопки масштабирования карты и управление мышью или жестами.
- Адаптация для компьютеров и мобильных устройств.
